# WORLDS-MOST-ADVANCED-SCANNING-TUNNELING-MICROSCOPE
A highly modified STM


WhisperSTM: The world’s first handheld, wireless STM. Built on a low-cost acrylic frame with a PCB by MechPanda, it uses an ultrasonic 25kHz self-tuning loop and a 3D feed-forward matrix to cancel hand tremors and scan atoms over Wi-Fi while physically holding it. Hardware and schematics are open-source; the core adaptive firmware engine is closed-source.
